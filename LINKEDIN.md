# Como adicionar o Code Solutions no LinkedIn (melhor forma)

O site https://ivamartins.github.io/code-solutions-site/ foi projetado para ser seu principal ativo profissional para atrair clientes via PJ.

A **melhor forma** de posicionar o site no LinkedIn (e a Code Solutions como marca de serviços) é criar uma entrada dedicada de **Experiência**.

**Por que uma "Experiência" dedicada é muito melhor do que só colocar no Featured ou About?**
- Colocar só no Featured ou no texto do About faz parecer "um projeto pessoal" ou portfólio.
- Criar uma **Experiência com o nome Code Solutions** transforma isso em uma entidade profissional real (mesmo sendo estrutura PJ individual).
- LinkedIn trata isso com muito mais peso em buscas internas e no perfil.
- Empresas que procuram "manutenção de legados", "Play Framework", "Elasticsearch", "agentes IA" ou "backend sênior Porto Alegre" encontram você com mais facilidade.
- É a abordagem usada por consultores seniores e especialistas independentes para posicionar sua marca de serviços.

**Importante (atualizado):** Você informou que já existe uma página "Code Solutions" no LinkedIn. Vamos usar isso a nosso favor em vez de ignorar.

**⚠️ Regra crítica de separação (CLT vs PJ):** 
Panvel (2012–2014) e Sicredi (2014–2021) foram realizados por você **como CLT / consultor externo** em outras empresas — **não** pela Code Solutions (PJ). Somente a partir de Quartile (2021+) os serviços foram prestados via a estrutura PJ. 
Nunca coloque esses clientes antigos na descrição da Experiência "Code Solutions", no About da página da empresa, nem em posts como se a empresa os tivesse atendido. O site já faz a separação clara ("Resultados da minha trajetória" + "A expertise que entrego hoje via Code Solutions (PJ) é construída sobre..."). Mantenha isso em todos os lugares.

A estratégia principal continua sendo: **adicione primeiro a Experiência usando o nome exato "Code Solutions"**. Isso faz o LinkedIn sugerir automaticamente a vinculação com a página existente.

## 4. Avalie e vincule a página existente "Code Solutions"

Como já existe uma página com esse nome:

1. Busque no LinkedIn por **"Code Solutions"** e abra a página da empresa que aparecer primeiro.
2. Analise rapidamente:
   - É relacionada a desenvolvimento de software, TI, consultoria ou legados?
   - Tem localização, posts ou dono claro?
   - Parece inativa ou de outra pessoa/atividade?
3. Volte na sua **Experiência** que você acabou de criar com nome "Code Solutions".
4. Clique em "Editar" na experiência → procure a opção **"Vincular à página da empresa"** ou similar. O LinkedIn costuma sugerir automaticamente a página existente quando o nome bate.
5. Se aparecer opção de reivindicar/administrar a página ("Claim this page", "Reivindicar página" ou "Gerenciar"), use se a página for adequada para você.
6. Se a página existente for claramente de outra pessoa/ramo diferente, não force. A simples entrada de Experiência com o nome "Code Solutions" já cria uma associação forte no seu perfil. Muitos consultores independentes operam assim.

**Alternativa se a página existente não servir:**
- Crie uma nova Company Page com nome mais específico, ex: "Code Solutions | Engenharia Backend e Agentes IA" ou "Code Solutions — Ivã Martins".
- Depois vincule manualmente na sua Experiência.

O mais importante já está feito: a Experiência dedicada aparece no seu perfil como atividade profissional estruturada.
